### 1.0.0

* Initial release of CinnaSpot (Spotlight-inspired launcher for Cinnamon).
* Added fast application search, window switcher sidebar, system info sidebar (CPU, RAM, Swap, Disk), and calculator.
* Added support for system actions (Shutdown, Suspend, Restart, Logout, Lock Screen) and script running (`sh` prefix).
* Implemented multi-monitor support (spawns on the active monitor where the mouse cursor is located).
* Relayout settings schema (`schema.json`) following the tabbed interface layout format (like gTile) for clean organization.
* Optimized screenshot image size and prepared metadata/file structure for Cinnamon Spices validation.
